# Diabetes Prediction Pipeline

A machine learning Model for predicting diabetes outcomes using SVM with SMOTE for handling class imbalance and StandardScaler for feature normalization.

## Overview
This project implements:
- **SMOTE** for class imbalance handling
- **StandardScaler** for feature standardization
- **SVM with linear kernel** for classification
- **Stratified train-test split** for evaluation
